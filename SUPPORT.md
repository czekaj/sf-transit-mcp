# Support

SF Bay Area Transit MCP is created by **Lucas Czekaj** and operated and published by **[Reindex Ventures LLC](https://reindexventures.com)**.

For questions or bugs, open a [GitHub issue](https://github.com/czekaj/sf-transit-mcp/issues) or email [contact@reindexventures.com](mailto:contact@reindexventures.com).

Include the AI app you use, what you expected, and what happened. If you run a local copy, include its version or commit if known. Use public landmarks in examples. GitHub issues are public; send personal trip details by email instead.

Send security reports privately using [Security](SECURITY.md). The [privacy policy](PRIVACY.md) explains who receives trip data, how it is handled, and how to contact the operator about privacy.

Transitous provides trip planning using available timetables and predictions. Missing trips or predictions may be caused by incomplete data or a service problem. Include the starting place, destination, and intended departure or arrival time so the problem can be investigated.
