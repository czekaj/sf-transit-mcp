# Support

SF Bay Area Transit MCP is created by **Lucas Czekaj** and operated and published by **[Reindex Ventures LLC](https://reindexventures.com)**.

For questions and ordinary bugs, open a [GitHub issue](https://github.com/czekaj/sf-transit-mcp/issues) or email [contact@reindexventures.com](mailto:contact@reindexventures.com).

Include the client you use, the project version or commit, what you expected, and what happened. Use public landmarks in examples. GitHub issues are public; send personal trip details by email instead.

Send vulnerability reports privately using [Security](SECURITY.md). The [privacy policy](PRIVACY.md) explains how requests pass through the client, hosting provider, and Transitous, and how to contact the operator about privacy.

Routing is supplied by Transitous and depends on available timetable and prediction data. A failed journey or missing prediction can reflect source data or service availability. Report the public-place example and the approximate travel time so the issue can be investigated.
